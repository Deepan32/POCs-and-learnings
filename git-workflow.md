\# Git Workflow



\## Steps for pushing changes



1\. Create a new branch from `main`.

2\. Make the required changes in the new branch.

3\. Check the changes using `git status`.

4\. Add the changes using `git add .`.

5\. Commit the changes using `git commit -m "message"`.

6\. Push the branch using `git push origin <branch-name>`.

7\. Create a Pull Request on GitHub.

8\. Get the changes reviewed and merge the PR into `main`.
